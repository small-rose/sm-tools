什么是Favicon？

Favicon（网站图标）是网站身份的重要组成部分，了解它的作用、格式和最佳实践

favorite 什么是Favicon？

Favicon（网站图标）是显示在浏览器标签页、书签栏、历史记录和移动设备主屏幕上的小型图标。它帮助用户快速识别和定位您的网站。

visibility视觉识别

Favicon是您网站的视觉标识，帮助用户在多个打开的标签页中快速找到您的网站。

branding_watermark品牌一致性

与您的品牌标识保持一致，增强专业性和可信度。

photo_size_select_small Favicon格式和尺寸

现代网站需要多种格式和尺寸的Favicon来适配不同的设备和浏览器：

格式 推荐尺寸 用途
ICO 16×16, 32×32, 48×48 传统浏览器兼容性
PNG 16×16, 32×32, 180×180 现代浏览器和移动设备
SVG 任意尺寸 高分辨率显示设备
Apple Touch Icon 180×180 iOS设备主屏幕

code 如何实现Favicon

在HTML文件的<head>部分添加以下代码来引入Favicon：

<!-- 基本Favicon -->
<link rel="icon" type="image/x-icon" href="/favicon.ico">

<!-- 多尺寸PNG图标 -->
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">

<!-- Apple Touch Icon -->
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">

<!-- 网站清单（可选） -->
<link rel="manifest" href="/site.webmanifest">

将以上代码添加到您的HTML文档的<head>部分，并确保相应的图标文件位于正确的路径。
